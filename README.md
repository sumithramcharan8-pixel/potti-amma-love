# Potti Amma Love 💛

A heartfelt Mother's Day tribute website built for Potti amma — featuring a beautiful animated dark background with floating petals, glowing orbs, and a typewriter message reveal with a surprise celebration at the end.

## Features

- Typewriter animation that types the full Mother's Day message letter by letter
- Rich animated background: jewel-tone glowing orbs, floating petals, and twinkling sparkles
- Surprise confetti/particle burst when the message finishes
- Fully responsive design
- No distracting branding — just the message

## Tech Stack

- **Frontend:** React + TypeScript + Tailwind CSS
- **Backend:** Motoko (Internet Computer canister)
- **Deployed on:** Internet Computer (ICP)
